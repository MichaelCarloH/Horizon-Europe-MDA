Artificial Intelligence (AI) is a branch of computer science that aims to create intelligent machines that can perform tasks that typically require human intelligence. These tasks include:

1. Visual perception
2. Speech recognition
3. Decision-making
4. Language translation
5. Problem-solving

AI systems can be trained using large amounts of data and can learn from experience to improve their performance over time. Machine learning, a subset of AI, focuses on developing algorithms that can learn patterns from data without being explicitly programmed.

Key applications of AI include:
- Natural Language Processing (NLP)
- Computer Vision
- Robotics
- Expert Systems
- Neural Networks
