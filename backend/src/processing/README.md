# Processing Module

This directory contains all document and data processing operations for the EuroRAG application.

## Files
- `document_processor.py` - Document parsing and processing
- `data_processor.py` - Data transformation and processing utilities
- `query_processor.py` - Query processing and optimization

## Purpose
This module handles all data processing tasks, including:
- Document parsing and text extraction
- Data cleaning and normalization
- Query processing and optimization
- Text preprocessing for vector embeddings

## Usage
Import the required processing functions from this module to handle document and data processing tasks throughout the application.
