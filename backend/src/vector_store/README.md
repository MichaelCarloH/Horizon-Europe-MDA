# Vector Store Module

This directory contains all vector store operations and utilities for the EuroRAG application.

## Files
- `vector_store.py` - Core vector store operations
- `update_vector_store.py` - Vector store update utilities
- `compare_embeddings.py` - Embedding comparison utilities

## Purpose
This module handles all vector store operations, including:
- Vector store initialization and management
- Embedding generation and storage
- Vector similarity search
- Embedding comparison and analysis

## Usage
Import the required vector store functions from this module to perform vector operations and similarity searches.
