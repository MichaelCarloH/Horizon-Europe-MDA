# Database Module

This directory contains all database-related operations and utilities for the EuroRAG application.

## Files
- `database.py` - Core database connection and configuration
- `create_database.py` - Database initialization and schema creation
- `view_database.py` - Database viewing and inspection utilities

## Purpose
This module handles all interactions with the underlying database, including:
- Database connection management
- Schema creation and updates
- Query execution
- Data retrieval and manipulation

## Usage
Import the required database functions from this module to interact with the database in other parts of the application.
